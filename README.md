# Turret Security System

Программа управления турелями из мода **OpenSecurity** для **OpenComputers** (Minecraft 1.7.10).
---

## Возможности

- Автоматическое наведение и стрельба
- Поддержка нескольких турелей
- Калибровка положения турели
- Белый список игроков
- Включение/выключение атаки по мобам и игрокам

---

## Требования

- Minecraft 1.7.10
- OpenComputers
- OpenSecurity
- Entity Detector (блок)

---

## Установка

- Установщик - wget -f https://raw.githubusercontent.com/HellBreezMix/turret/main/install.lua install.lua
- Запускаем установщик - /home/install.lua
- Запуск программы - turret

---
## FAQ

- 1 ставим детектор и сразу на него снизу вешаем турель (вплотную)
- по умолчанию время на калибровку 5 секунд, если нужно увеличить, почти в самом начале кода находим "local CALIB_DELAY = 5.0" меняем значение далее ctrl+S ctrl+W
- ставим 1ю турель, нажимаем "калибровка" во время таймера встаем идеально под турель и упираемся в нее головой.
- радиус действия установлен 64 блока, по факту может быть меньше, если так - ограничение не со стороны кода
