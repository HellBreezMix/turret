# Turret Security System

Программа управления турелями из мода **OpenSecurity** для **OpenComputers** (Minecraft 1.7.10).
---

## Возможности

- Автоматическое наведение и стрельба
- Поддержка нескольких турелей
- Калибровка положения турели
- Белый список игроков
- Включение/выключение атаки по мобам и игрокам

---

## Требования

- Minecraft 1.7.10
- OpenComputers
- OpenSecurity
- Entity Detector (блок)

---

## Установка

- Установщик - wget -f https://raw.githubusercontent.com/HellBreezMix/turret/main/install.lua install.lua
- Запускаем установщик - /home/install.lua
- Запуск программы - turret.lua
