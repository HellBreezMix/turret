# Turret Security System

Программа управления энергетическими турелями из мода **OpenSecurity** для **OpenComputers** (Minecraft 1.7.10).
---

## Возможности

- Автоматическое наведение и стрельба
- Поддержка нескольких турелей
- Калибровка положения турели
- Белый список игроков
- Включение/выключение атаки по мобам и игрокам

---

## Требования

- Minecraft 1.7.10
- OpenComputers
- OpenSecurity
- Entity Detector (блок)

---

## Установка
установщик:
wget -f https://raw.githubusercontent.com/HellBreezMix/turret/main/install.lua install.lua
запускаем установщик:
home/install.lua
запуск:
turret.lua
